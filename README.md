"# Phazon - Intelligent Academic Portal\n\nPhazon is a modern, high-profile academic management portal built with a decoupled 3-tier architecture using React.js for the client and Express.js for the API server.\n\n---\n\n## Getting Started in VS Code\n\n### 1. Open the Project\n1. Launch **Visual Studio Code**.\n2. Click **File > Open Folder...** and select this project directory (`PHAZON`).\n\n### 2. Install Project Dependencies\nBefore running the project for the first time, ensure all package dependencies are installed. Open a terminal in VS Code (press ``Ctrl + ` `` or go to **Terminal > New Terminal**) and run:\n```bash\nnpm install\n```\n\n### 3. Run the Full Stack\nWe have pre-configured a concurrent development command. Run the following command in the terminal to start **both** the Express API server and the Vite React client concurrently:\n```bash\nnpm run dev:all\n```\n\nOnce running:\n- **Client Application**: Access at [http://localhost:5173/](http://localhost:5173/)\n- **Express Backend API**: Access at [http://localhost:3001/](http://localhost:3001/)\n\n---\n\n## Alternate: Run Separately\nIf you prefer to run the client and server in separate terminal windows:\n\n### Terminal 1: Start Backend API Server\n```bash\nnpm run server\n```\n*Port: `3001`*\n\n### Terminal 2: Start Vite Client Server\n```bash\nnpm run dev\n```\n*Port: `5173`*\n"
